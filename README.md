# 空间站 Space Station

SillyTavern 角色卡、世界书与预设编辑器。项目是纯前端 SPA/PWA，数据保存在浏览器 IndexedDB 中，可部署到 GitHub Pages。

## 功能

- 角色卡创建、导入、导出、备份与恢复
- 角色基础信息、头像、开场白、正则脚本和深度提示编辑
- 世界书条目编辑、排序、复制和触发条件管理
- AI 预设采样参数、模板、提示词条目、提示词池和正则脚本编辑
- 亮暗模式、强调色与全局字体切换，支持添加经过验证的网络字体
- 可选的本地 Token 预估，覆盖角色卡、世界书与预设的主要文本
- 通过 GitHub Gist 手动云同步本地数据

## v1.1.6

- 新增默认关闭的本地 Token 预估，可选择 Gemini（Gemma 近似）、Claude（粗略估算）或 DeepSeek V4
- 角色卡主要文本、各开场白、深度提示、世界书条目及预设提示词均可独立显示预估值
- 预设显示“当前启用 / 全部池”总计并自动排除占位条目，世界书显示全部条目总计
- 分词器只在启用后按需加载，并在浏览器本地 Worker 中运行；编辑内容不会发送到远程分词服务
- 世界书长名称改为完整换行显示，条目数固定在信息行最右侧

所有 Token 数字都只是按当前字面文本计算的本地预估，不等同于酒馆最终请求的精确 Token 数、费用或上下文占用。

当前版本：v1.1.6。

## 本地开发

```bash
npm install
npm run dev -- --host localhost --port 5173
```

本地调试优先使用 `http://localhost:5173/`。如果浏览器曾经注册过旧版 PWA，请先清理该域名下的 Service Worker 和站点缓存，避免旧资源干扰字体、样式和构建文件。

## 构建

```bash
npm run build
```

## 部署

```bash
npm run deploy
```

部署目标为 GitHub Pages，生产构建产物位于 `dist/`。
