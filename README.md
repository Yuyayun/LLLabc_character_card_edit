# 空间站 Space Station

SillyTavern 角色卡、世界书与预设编辑器。项目是纯前端 SPA/PWA，数据保存在浏览器 IndexedDB 中，可部署到 GitHub Pages。

## 功能

- 角色卡创建、导入、导出、备份与恢复
- 角色基础信息、头像、开场白、正则脚本和深度提示编辑
- 世界书条目编辑、排序、复制、触发条件管理及 SillyTavern 独立 JSON 互导
- AI 预设采样参数、模板、提示词条目、提示词池和正则脚本编辑
- 亮暗模式、强调色与全局字体切换，支持添加经过验证的网络字体
- 可选的本地 Token 预估，覆盖角色卡、世界书与预设的主要文本
- 通过 GitHub Gist 手动云同步本地数据

## v1.1.9

- 世界书主页面支持导入 SillyTavern 原生独立世界书 JSON，并区分 JSON、`entries` 和条目结构错误
- 独立世界书与角色卡内嵌世界书都可直接导出为 UID 对象格式，导出使用当前内存内容和四空格缩进
- 完整转换位置、递归、概率、分组、角色过滤、触发条件等字段，同时保留未知顶层、条目和扩展字段
- 重复或无效 UID 会按稳定规则仅在导入/导出副本中修复，不随机改写当前数据库条目
- 同名导入会先确认并原位覆盖，保留原数据库 ID、创建时间以及所有角色卡绑定

## v1.1.8

- Regex 支持独立 JSON 单条/批量导入导出，兼容 SillyTavern 的裸对象、裸数组、四空格缩进与文件名规则
- 角色卡和预设使用同一套 Regex 工具栏、选择模式、排序菜单及批量操作
- 支持在已保存的角色卡与预设之间复制或移动 Regex；移动使用 Dexie 事务，失败时完整回滚
- 旧 `placement: 0` / `placement: 4` 会按 SillyTavern 规则即时迁移，未知扩展字段继续保留
- 未保存页面与 `/new` 记录会禁止跨对象转移，避免旧数据库内容覆盖当前编辑状态

## v1.1.7

- 拆分角色卡、预设、内嵌世界书、Regex 与文件下载模块，保留原有导入导出接口和数据格式
- 角色卡与预设改用同一套 Regex 编辑核心，保留预设排序/复制与角色卡现有布局差异
- 世界书 `delay_until_recursion` 同时兼容布尔值和数字层级；布尔值显示为 1/0，编辑后写回数字
- 移除预设编辑器内部容易误解的旧“导入”按钮，预设主页面的完整导入不变
- 新增固定格式夹具与 Vitest 往返测试，覆盖未知字段、预设顺序组、Regex、世界书及 PNG chunk

Token 预估仍只按当前字面文本在本地计算，不等同于酒馆最终请求的精确 Token 数、费用或上下文占用。

当前版本：v1.1.9。

## 本地开发

```bash
npm install
npm run dev -- --host localhost --port 5173
```

本地调试优先使用 `http://localhost:5173/`。如果浏览器曾经注册过旧版 PWA，请先清理该域名下的 Service Worker 和站点缓存，避免旧资源干扰字体、样式和构建文件。

## 构建

```bash
npm run test:run
npm run lint
npm run build
```

## 部署

```bash
npm run deploy
```

部署目标为 GitHub Pages，生产构建产物位于 `dist/`。
