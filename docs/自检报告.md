## 四、技术债务

1. **PWA 完全未实施** — 无 manifest.json，无 service worker，无 vite-plugin-pwa
2. **独立世界书编辑器** (WorldBookEditor) 需要大幅重写以对齐 EditorWorldBook 的字段完整度
3. **ErrorBoundary** 缺失 — 任何渲染错误会导致白屏
4. **无障碍** — 多处键盘导航和屏幕阅读器支持不足
5. **入口级扩展字段** — 导入时已修复回退读取，但导出格式仍将扩展字段嵌套在 `extensions` 下，可能与其他工具不完全互操作
