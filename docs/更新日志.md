## 2026-06-07 — v1.1.0-hotfix

### Bug 修复

- **修复 prompt_order 多角色时选错排序**：酒馆预设 JSON 中 `prompt_order` 包含多个角色的排序（默认模板 100000 + 自定义角色），此前取第一个角色导致链接列表显示默认模板条目。现改为取条目数最多的角色。
- **修复解锁状态不持久**：`verifyKey` 验证通过后忘记写入 IndexedDB，导致刷新页面后解锁丢失。
- **修复导航栏解锁后不更新**：AppLayout 仅在挂载时检查一次解锁状态，现改为每次路由变化都重新检查。
- **修复预设列表 DB 索引缺失**：`presets` 表缺 `updated_at` 索引，`orderBy("updated_at")` 报错。
- **修复导入酒馆预设名称为空**：酒馆 JSON 无顶层 `name` 字段，改用文件名作为预设名称。
- **手机端导航栏精简**：窄屏下所有导航项改为图标，解决按钮拥挤问题。

### 改进

- **项目更名**：从「角色卡编辑器」更名为「空间站 Space Station」。

### 影响范围

- `src/pages/PresetEditor.tsx` — `buildOrder` 多角色取最多条目
- `src/lib/lockKey.ts` — `verifyKey` 自动写库
- `src/lib/db.ts` — Dexie v6 修复 presets 索引
- `src/lib/parser.ts` — 文件名 fallback 名称
- `src/components/layout/AppLayout.tsx` — 手机端图标化 + 路由感知解锁
- `index.html` / `vite.config.ts` / `CLAUDE.md` — 项目更名

## 2026-06-02 — 灵感笔记排序修复 & 拖拽排序

### Bug 修复

- **修复上下移动按钮的 disabled 条件颠倒**。列表按最新优先排列（index 0 = 最新），但 ↑ 按钮错误地在底部（最旧）才禁用、↓ 按钮在顶部（最新）才禁用，导致最新备忘只能下移、最旧备忘只能上移。已修正为 ↑ 在顶部禁用、↓ 在底部禁用。

### 影响范围

- `src/components/editor/EditorMemos.tsx`
  - `moveMemo(index, direction)` → 重构为通用 `reorderMemo(fromIndex, toIndex)`，按钮与拖拽共用逻辑
  - 新增 `dragIndex` / `dragOverIndex` 状态及 5 个拖拽事件处理器
  - 新增 `GripVertical` 图标（lucide-react）
- 时间轴视图无变化（按创建时间分组，不涉及排序）
- **完全兼容旧数据**，不涉及数据库 schema 变更
