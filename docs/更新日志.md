# 更新日志

## 2026-06-04 — 云同步压缩加速 & PWA 更新提醒

### 改进

- **云同步下载大幅提速**：引入 gzip 压缩 + base64 编码，数据体积减少 80-85%。上传/下载均使用 v2 压缩格式（`_v2.json`），下载保留旧版明文文件 fallback 供过渡期使用。旧客户端会收到 PWA 更新提醒后刷新至新版。
- **自动上传增加进度提示**：开启「保存时自动上传」后，保存时会依次显示「正在同步到云端…」→「云端同步完成」或「云端同步失败，请检查设置」。
- **下载跳过冗余 Token 校验**：此前下载需要额外请求 `/user` 验证 token 权限（配置时已验证），现已移除该步骤，下载减少一次网络往返。
- **PWA 新版本提醒**：检测到新版本部署后弹出提示"有新版本可用"，用户点击"刷新"即可立即更新，不再需要手动刷新页面。
- **自动上传增加进度提示**：开启「保存时自动上传」后，保存时会依次显示「正在同步到云端…」→「云端同步完成」或「云端同步失败，请检查设置」。
- **下载跳过冗余 Token 校验**：此前下载需要额外请求 `/user` 验证 token 权限（配置时已验证），现已移除该步骤，下载减少一次网络往返。
- **PWA 新版本提醒**：检测到新版本部署后弹出提示"有新版本可用"，用户点击"刷新"即可立即更新，不再需要手动刷新页面。

### 影响范围

- `src/lib/cloudSync.ts` — 新增 `compressData`/`decompressData`/`v2Filename`/`readGistFileContent`；`uploadToGist` 同时写入 v2 压缩文件和旧明文文件；`downloadFromGist` 优先读 v2，fallback 旧格式，移除冗余 `requireGistScope`
- `src/components/PWAUpdater.tsx` — 新增，使用 `useRegisterSW` 监听 Service Worker 更新，弹出刷新提示
- `src/main.tsx` — 挂载 `PWAUpdater`
- `src/vite-env.d.ts` — 新增，`virtual:pwa-register/react` 类型声明
- `vite.config.ts` — `registerType` 从 `autoUpdate` 改为 `prompt`
- **完全兼容旧数据**，旧版客户端仍可读取 Gist 中的明文文件，新版优先读压缩文件

## 2026-06-02 — 灵感笔记排序修复 & 拖拽排序

### Bug 修复

- **修复上下移动按钮的 disabled 条件颠倒**。列表按最新优先排列（index 0 = 最新），但 ↑ 按钮错误地在底部（最旧）才禁用、↓ 按钮在顶部（最新）才禁用，导致最新备忘只能下移、最旧备忘只能上移。已修正为 ↑ 在顶部禁用、↓ 在底部禁用。

### 新功能

- **灵感卡片视图中支持拖拽排序**。左侧新增 ⋮⋮ 拖拽手柄，拖拽时源卡片半透明、目标位置显示虚线边框 + 蓝色光环。拖拽结束后自动重分配 `sort_order`，支持跨距离移动。

### 影响范围

- `src/components/editor/EditorMemos.tsx`
  - `moveMemo(index, direction)` → 重构为通用 `reorderMemo(fromIndex, toIndex)`，按钮与拖拽共用逻辑
  - 新增 `dragIndex` / `dragOverIndex` 状态及 5 个拖拽事件处理器
  - 新增 `GripVertical` 图标（lucide-react）
- 时间轴视图无变化（按创建时间分组，不涉及排序）
- **完全兼容旧数据**，不涉及数据库 schema 变更
