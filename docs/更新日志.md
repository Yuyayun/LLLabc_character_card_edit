# 更新日志

## 2026-07-16 — 开发中

### 新功能

- **全局字体切换**：设置页新增汇文仿宋、澹雅明体、寒蝉全圆体、系统黑体与系统宋体预设；汇文仿宋继续作为默认字体，旧用户首次升级时页面观感不变。
- **自定义网络字体**：可填写显示名称、CSS `font-family` 与远程 CSS 地址，验证成功后加入字体库并立即启用。

### 稳定性

- **真实字体加载验证**：动态 CSS 加载成功后继续通过浏览器字体 API 验证目标 family；不支持完整字体 API 的 WebView 使用实际字形渲染探针降级验证。
- **失败不污染设置**：错误 URL、family 不匹配或字体文件失败时保留当前字体，不写入启用状态；页面同时只保留一个激活的动态字体 link。
- **持久化与响应式**：字体选择及自定义字体库保存在独立 localStorage key，刷新后恢复；设置卡片已验证桌面和手机端布局。

### 影响范围

- `src/components/layout/FontProvider.tsx` / `font-context.ts` — 字体状态、加载和验证
- `src/lib/fontSettings.ts` — 内置预设、规范化与持久化
- `src/pages/Settings.tsx` — 字体选择与自定义字体管理界面
- `src/index.css` — 全局 `--app-font-family` 接入
