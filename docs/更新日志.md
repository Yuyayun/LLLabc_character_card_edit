## 2026-07-23 — v1.1.6

### 新功能

- **可选的本地 Token 预估**：设置页新增“Token 预估”开关，默认关闭；开启后可在 Gemini（Gemma 近似）、Claude（粗略估算）和 DeepSeek V4 三种方式中单选。选择保存在 `localStorage.space-station-token-settings-v1`。
- **角色卡分项统计**：角色描述、性格、场景、首条消息、对话示例、各条备选/群聊开场白、深度提示、系统提示及历史后指令分别显示预估值；作者备注、正则、灵感笔记和世界书内容不混入角色卡字段统计。
- **预设统计**：普通提示词在列表、提示词池及编辑区显示单条预估；编辑页同时显示“当前启用”和“全部池”总计。占位条目不显示、不参与任何 Token 统计；当前启用总计只计算当前顺序组中 `enabled: true` 且实际存在的普通提示词内容。
- **世界书统计**：独立与角色卡内嵌世界书的条目内容均显示单条预估，编辑区显示全部条目总计。

### 改进

- **按需加载与本地计算**：分词器运行库和模型资源仅在用户主动开启并选择估算方式后加载；编码工作放在 Web Worker 中，输入文本不上传到远程分词服务。
- **缓存与切换保护**：相同文本复用有界内存缓存；切换、关闭或重新选择分词器时终止旧 Worker、清除缓存并丢弃过期结果，避免旧模型数字回填到新状态。
- **世界书长名称布局**：世界书列表与编辑区不再截断名称，窄屏下完整自动换行；来源/绑定信息保留在左侧，条目数尽量贴近信息行右侧，页面不会因此产生横向滚动。

### 准确性、隐私与兼容性

- **所有数字仅为预估**：只统计编辑器当前可见字段的字面文本，不展开酒馆宏，不拼接聊天记录或酒馆最终消息格式，不能用作精确费用或上下文窗口判断。
- **估算边界明确**：Gemini 使用 Gemma 分词器近似；Claude 使用 Anthropic 公开的旧版分词器，只能粗略参考；DeepSeek 选项在界面统一显示为“DeepSeek V4”。资源来源、固定修订、校验值和许可证见 `public/tokenizers/THIRD_PARTY_NOTICES.md`。
- **PWA 体积控制**：大型分词器文件和 Tokenizer Worker 不进入安装时预缓存；首次使用后由运行时缓存保存，避免未开启功能的用户承担模型下载。
- **现有数据不变**：本轮没有提升 Dexie 数据库版本，也不迁移或改写角色卡、世界书和预设。普通“清空数据”保留 Token 偏好，“重置应用”会一并删除该设置。

- 360 px 手机宽度下验证世界书长名称完整换行、条目数右对齐且无横向溢出

## 2026-07-22 — v1.1.5

### 改进

- **未保存修改保护**：角色卡、世界书与预设编辑页统一接入离开确认；站内跳转、返回、刷新、关闭页面及切换当前编辑对象时都会检查实际修改，保存后立即恢复为可安全离开状态。
- **数据清理分级**：原“清空全部数据”拆分为“清空数据”和“重置应用”。前者只清除角色卡、世界书、预设及其备忘录和聊天记录；后者额外清除 API、云同步、应用设置、字体与主题偏好。
- **关联数据同步清理**：删除角色卡时一并删除对应备忘录和聊天记录；删除独立世界书时自动解除角色卡绑定，避免残留失效引用。
- **酒馆文件往返保真**：角色卡、内嵌世界书、世界书条目、正则脚本及预设导入后保留编辑器未识别的原始字段；导出时只覆盖本应用实际管理的字段。
- **预设顺序结构保留**：兼容并保留酒馆预设的多组 `prompt_order`，编辑器只修改当前角色组（`character_id: 100001`），其他角色组原样导出。

### Bug 修复

- **修复正则开关文案**：角色卡与预设正则的启用开关会随真实状态显示“已启用”或“已禁用”，避免开关打开时仍显示为已禁用。
- **修复延迟保存丢失风险**：离开备忘录页面时会提交尚未落库的延迟保存内容和编辑时长记录。

### 稳定性与兼容性

- **原子化数据操作**：清空、重置以及带关联数据的删除均放入 Dexie 事务中执行；任一步失败时整组操作回滚，避免只删掉一部分数据。
- **现有存储兼容**：本轮没有提升 Dexie 数据库版本，不主动迁移或重写现有记录；旧数据继续按当前结构读取。
- **云端覆盖暂缓**：本版未改动 Gist 下载覆盖与合并逻辑，相关保护留待后续云同步专项处理。

- **代码质量清理**：修复 React Hooks、Fast Refresh 与 TypeScript ESLint 的既有错误；清理过程不改变页面行为和数据格式。
