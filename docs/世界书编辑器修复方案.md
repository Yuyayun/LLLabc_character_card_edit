# 世界书编辑器修复方案

基于酒馆本体 (`public/scripts/world-info.js` + `index.html` entry_edit_template) 对比检查报告的修复计划。

## 改动概览

涉及文件：
- `src/types/index.ts` — 新增少量字段
- `src/lib/helpers.ts` — 默认值对齐
- `src/lib/parser.ts` — import 适配
- `src/components/editor/EditorWorldBook.tsx` — 主战场，结构重排

## 一、类型修正

### 1.1 新增 `vectorized` 到 WorldBookEntry 顶层

```ts
vectorized: boolean  // 向量化条目，默认 false
```

### 1.2 新增 `character_filter` 到 WorldBookEntry 顶层（独立于 extensions）

```ts
character_filter_names?: string[]
```

### 1.3 确认 `addMemo` 字段

酒馆有 `addMemo: boolean`，用于展开/收起额外的注释区。目前我们缺失。

## 二、头部栏重排

酒馆头部从左到右为：展开箭头 → 开关 → 评论 → 状态(🔵🟢🔗) → 位置 → Depth → Order → 概率% → 操作按钮

我们的新头部结构：

```
[▼] [Switch] [📝title] [🔵/🟢/🔗 dropdown] [position▼] [depth#] [order#] [prob%#] [复制] [删除]
```

要点：
- **状态下拉**：三选一 `constant` / `normal` / `vectorized`，选 constant → `constant=true, vectorized=false`；选 normal → 两者 false；选 vectorized → `vectorized=true, constant=false`
- **位置下拉**：10 个 option（前7个 + atDepth 拆3个角色）
  - `0`: ↑Char (角色定义前)
  - `1`: ↓Char (角色定义后)
  - `5`: ↑EM (示例消息顶部)
  - `6`: ↓EM (示例消息底部)
  - `2`: ↑AN (作者注上方)
  - `3`: ↓AN (作者注下方)
  - `4 / role=0`: @D ⚙️ (深度-系统)
  - `4 / role=1`: @D 👤 (深度-用户)
  - `4 / role=2`: @D 🤖 (深度-助理)
  - `7`: ➡️ Outlet
  选中 atDepth 时，同一行显示 depth 数字输入；选中 outlet 时显示 outlet_name 输入
- **深度输入**：仅 atDepth 时可见，否则隐藏
- **删除**：保留

---

## 三、展开区重组

按酒馆顺序分成以下段落：

### 3.1 关键词与逻辑
- 主触发词输入 + 二级触发词输入
- selectiveLogic 下拉 (AND_ANY / NOT_ALL / NOT_ANY / AND_ALL)
- selective checkbox (启用二级触发词)

### 3.2 内容编辑
- 内容 textarea + token 计数（简单按 `/[一-鿿]|[a-zA-Z]+/` 估算）
- UID 显示

### 3.3 覆盖设置
- outlet_name（仅 position=7 可见）
- scan_depth
- **case_sensitive**：三态下拉 (使用全局 / 是 / 否) → null/true/false
- **match_whole_words**：同上
- **use_group_scoring**：同上
- automation_id

### 3.4 递归控制
- exclude_recursion checkbox（非递归激活）
- prevent_recursion checkbox（防止递归）
- delay_until_recursion 数字输入
- ignore_budget checkbox

### 3.5 分组与时间
- group 输入 + group_override checkbox + group_weight 数字
- sticky / cooldown / delay 数字输入

### 3.6 匹配范围
6 个 match_* checkbox，一行排开

### 3.7 过滤
- 角色过滤：触发词输入 + tags 输入 + exclude checkbox
- 触发类型过滤：triggers 多选

### 3.8 底部
- probability 数字 + useProbability checkbox
- addMemo checkbox（展开额外注释，暂不实现功能仅存数据）
- constant / selective 保留在此（但 constant 已由头部状态下拉控制，此处只读或同步）

## 五、Parser 适配

- `normalizeWorldBook`：读取 `entry.vectorized`，正确读取 `character_filter_*`
- `normalizeEntryExtensions`：case_sensitive/match_whole_words/use_group_scoring 保持 nullable 读取
- 导出 `buildSpecData`：vectorized / character_filter_* 写入 on-disk 位置

## 六、实现顺序

1. 类型 + 默认值 + parser（小改动，先跑通编译）
2. 头部栏重写（状态选择器 + 位置 atDepth 拆分 + depth 条件显示）
3. 三态下拉（case_sensitive / match_whole_words / use_group_scoring）
4. 角色过滤（character_filter）
5. 展开区重组
6. 编译验证 + 功能测试
